# Financial Data Ukraine

Open financial data, references and educational resources about loans, banking, personal finance and financial services in Ukraine.

## About

This repository is maintained by [Finvybir](https://finvybir.com.ua/) — a Ukrainian financial information platform focused on loans, banking products, consumer finance and financial literacy.

The goal of this repository is to publish useful public resources, structured financial information, reference materials and datasets related to the Ukrainian financial market.

## Planned content

- Public financial datasets
- Loan and banking terminology
- Consumer finance reference materials
- Structured comparison data
- Simple financial calculators and examples
- Research materials related to the Ukrainian financial market
